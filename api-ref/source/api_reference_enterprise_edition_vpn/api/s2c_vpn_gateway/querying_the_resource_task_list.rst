Querying the Resource Task List
===============================

Function
--------

This API is used to query the resource task list.

Calling Method
--------------

For details, see :ref:`Calling APIs <en-us_topic_0000001807530276>`.

URI
---

GET /v5/{project_id}/vpn-gateways/jobs

.. table:: **Table 1** Parameter description

   +------------+--------+-----------+---------------------------------------------------------------------------------------------------------------------------------------+
   | Parameter  | Type   | Mandatory | Description                                                                                                                           |
   +============+========+===========+=======================================================================================================================================+
   | project_id | String | Yes       | Specifies a project ID. You can obtain the project ID by referring to :ref:`Obtaining the Project ID <en-us_topic_0000001807530332>`. |
   +------------+--------+-----------+---------------------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 2** Parameter in a query request

   +-----------------+-----------------+-----------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | Parameter       | Type            | Mandatory       | Description                                                                                                                                                                                                                                       |
   +=================+=================+=================+===================================================================================================================================================================================================================================================+
   | resource_id     | String          | No              | Specifies a resource ID.                                                                                                                                                                                                                          |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | limit           | Integer         | No              | Specifies the number of records returned on each page during pagination query.                                                                                                                                                                    |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
   | marker          | String          | No              | -  Specifies the start flag for querying the current page. If this parameter is left blank, the first page is queried. The **marker** for querying the next page is the **next_marker** in the **page_info** object returned on the current page. |
   |                 |                 |                 | -  This parameter must be used together with **limit**.                                                                                                                                                                                           |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Request
-------

-  Request parameters

   None

-  Example request

   #. Query all resource tasks.

      .. code-block:: text

         GET https://{Endpoint}/v5/{project_id}/vpn-gateways/jobs

   #. Query resource tasks based on a specified resource ID.

      .. code-block:: text

         GET https://{Endpoint}/v5/{project_id}/vpn-gateways/jobs?resource_id={resource_id}

-  Response parameters

   Returned status code 200: successful query
